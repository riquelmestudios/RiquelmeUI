## About

**RiquelmeUI** é uma biblioteca de interface criada para facilitar o desenvolvimento de scripts em Roblox com Lua.

O foco do projeto é entregar uma UI moderna, organizada, leve e fácil de integrar, evitando que o desenvolvedor precise perder tempo montando tudo do zero.

A proposta é simples: você importa a interface, chama as funções principais e já começa a usar no seu script.

---

## Main Goals

- Reduzir tempo de desenvolvimento
- Fornecer uma interface limpa e profissional
- Facilitar a criação de hubs, menus e painéis
- Manter a estrutura organizada
- Deixar a implementação simples para qualquer projeto Lua no Roblox

---

## Features

- Design moderno e minimalista
- Estrutura leve e otimizada
- Fácil integração em scripts
- Organização pensada para projetos profissionais
- Componentes prontos para uso
- Visual limpo e agradável
- Compatível com diferentes estilos de projeto
- Código simples de adaptar

---

## Why Use RiquelmeUI

Criar interface do zero em todo projeto costuma gastar muito tempo, deixa o código mais bagunçado e atrasa a evolução do script.

Com a **RiquelmeUI**, o processo fica mais rápido porque você já começa com uma base pronta, bem estruturada e visualmente mais bonita.

Isso ajuda principalmente em projetos como:

- Hubs de scripts
- Sistemas administrativos
- Menus de configuração
- Ferramentas internas
- Interfaces personalizadas
- Projetos privados ou públicos
